# Shared VS Code workspace

Open `app_laundry.code-workspace` from the repository root.

The workspace expects these folders:
- `backend`
- `dashboard`
- `landingpage`
- `docs`

If `docs` does not exist yet, create it or remove that folder entry from the workspace file.

VS Code will recommend extensions. Each developer must install the recommendations locally.

Workspace settings are shared through Git. Personal settings such as theme, font, keybindings, and installed fonts remain local to each laptop.
